# FI Mining Bot v7.1 — настоящий Telegram-бот

Единый файл `bot.js`. Чистый Node.js — **здесь ничего не нужно устанавливать**
зависимостей нет.

---

## 1. Включение (5 минут)

1. Открой **@BotFather** в Telegram → `/newbot`
2. Запиши имя (например, `FI Mining Bot`) и username (напр. `fi_coin_mining_bot`).
3. BotFather выдаст **токен** вида `1234567890:AA...xyz123`
4. Открой `config.json` и подставь его в поле `"token"`
5. Двойной клик по `start-fi-bot.bat` (консоль останется открытой — это норм: бот работает).
6. Открой своё меню и нажми `/start`.

---

## 2. Функционал игрока

| Команда | Что делает |
|---|---|
| `/start` | регистрация + кнопочное меню |
| `/profile` | профиль: USD, FI, мощность, статистика |
| `/market` | рынок FI: купить / продать (диалог с вводом суммы, или «все») |
| `/shop` | магазин майнеров (6 позиций, цена растёт каждый купленный +18%) |
| `/top` | топ игроков по капиталу |
| `/price` | текущая цена и запас FI в игре |
| `/bonus` | дневной бонус |
| `/work` | подработка |

Майнинг — пассивный: автоматически каждый тик (30 сек) начисляются FI по
мощности.

---

## 3. STAFF-консоль (когда создаёшь FI)

В чате бота напиши `/staff` и потом **пароль** (config.json → `staffPassword`,
по умолчанию `FI-ADMIN-2026`).
⚠️ **Первый вошедший с паролем становится владелец (OWNER)** — аккуратно!

Кнопочное меню:

- **🪙 Выдать монеты** — «ник сумма» (напр. `steve 500`) или `* 100` — всем
- **💵 Выдать USD** — то же самое
- **📈 Цена ↑ / 📉 Цена ↓** — ±1/5/10/25%, ×2, ÷2
- **🎯 Цена X** — установить точно
- **❄️ Заморозить / ▶️ Отпустить** — стоп движения курса (цена не меняется сама, пока не разморозишь)
- **👥 Игроки** — карточка игрока: выдать/забрать FI и USD, бан/разбан, обнулить
- **🚫 Баны** — список забаненных, разбан по нажатию
- **⚙️ Настройки** — вся тема + экономика (см. ниже)
- **📢 Всем сообщение** — рассылка всем игрокам
- **📜 Журнал** — последние действия staff

Дальше быстрые текстовые команды (только staff): `/give ник 100 fi|usd`,
`/pump 10`, `/dump 10`, `/freeze`, `/ban @ник причина`, `/unban @ник`,
`/banlist`.

---

## 4. Баны

- В карточке игрока кнопка **🚫 Забанить / ✅ Разбанить**.
- Или командами: `/ban @ник причина…`, `/unban @ник`, `/banlist`.
- Игроку в ЛС уведомления придут автоматически.
- Забаненный не может играть (рынок, магазин, бонус, работа закрыты) и видит
  только причину разбана (или «обратись к администрации»).
- В `config.json` есть `ownerOnlyBans`:
  - `false` (по умолчанию) — бан/разбан доступен всему staff
  - `true` — бан/разбан **только владелец** 👑
- Владельца нельзя забанить.

## 5. Настройки / «тема» (⚙️ Настройки → внутри STAFF)

Всё можно менять **без перезапуска**, из бота:

| Раздел | Что настраивается |
|---|---|
| 🎨 Тема | название монеты (FI), эмодзи (🪙), заголовок бота, текст приветствия |
| 📊 Рынок | стартовая цена, волатильность %/тик, шанс события %/тик, спреды покупки/продажи |
| 💰 Экономика | стартовые USD/FI, майнинг FI за TH/час, интервал и оплата работы, дневной бонус |

Изменения сразу пишутся в `data/state.json` и живут между перезапусками.

Для владельца также:
- **➕/➖ Staff** — выдать/снять админ-права другим игрокам
- **🧯 Сбросы**: счет (обнулить) рынок · обнулить балансы · удалить всех игроков
  (требуют подтверждение словом «да»)

---

## 6. Данные и безопасность

- Всё хранится локально в `data/state.json`. Делай бэкап этого файла.
- Файл конфига `config.json` (токен, пароль) — никому не передавай.
- Рынок отталкивается от тренда (цена возвращается к нему со временем) и дышит
  волатильностью + редкими событиями — оба параметра настраиваются в ⚙️ Настройки.

---

## 7. Как работает консоль цен

- `/pump 10` — поднять цену на 10%, `/dump 10` — уронить.
- Кнопки в консоли: `+1 +5 +10 +25%`, `✖2`, `÷2` и точная установка `🎯 Цена X`.
- При **заморозке** ❄️ курс висит на месте, пока не нажмёшь «Отпустить».
- Все выдачи и вмешательства в цену пишутся в журнал действий (`📜 Журнал`) —
  видно, кто и когда двигал курс.

## 8. Облачный хостинг 24/7 (Render)

Бот и его HTTP-API работают в облаке — ПК выключать можно.

1. Создай свободный PAT на GitHub (если ещё нет): Settings → Developer settings → Personal access tokens → Classic (repo) — он нужен для синка состояния data/state.json.
2. render.com → Sign in with GitHub → New → Web Service → выбери репозиторий fi-mining-bot.
3. Настройки: Language — Node, Build Command — пусто, Start Command — node bot.js, Instance — Free.
4. Environment → добавь переменные:
   - BOT_TOKEN — токен от @BotFather
   - GH_TOKEN — тот же GitHub PAT
   - GH_REPO — имя/fi-mining-bot (необязательно, есть дефолт)
   - PUBLIC_URL — https://ИМЯ-СЕРВИСА.onrender.com (бот запушит api.json в репо, и Mini App найдёт API)
5. Deploy → в логах жди: «☁️ Состояние загружено из GitHub», «🌐 API онлайн».
6. UptimeRobot → Add New Monitor (HTTP) → URL https://ИМЯ-СЕРВИСА.onrender.com/health → интервал 5 минут — чтобы free-инстанс не засыпал.

Mini App на GitHub Pages (index.html) сам читает api.json и ходит в облако. После первого деплоя полностью закрой и заново открой Mini App.
